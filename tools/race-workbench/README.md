# Longinus 调参与回放

在 Windows 双击 `Open Longinus.cmd`。也可以在本目录运行 `python launch.py`。默认地址是 `http://127.0.0.1:8768/`，只监听本机，打开后无需网络。遇到端口占用可以关闭已打开的工作台或运行 `python launch.py --port 8769`。标定表的本机草稿随浏览器和端口保留。关闭启动窗口会停止服务，浏览器里的试跑清单需要用「保存本趟归档」保存后带走。

## 试跑回放

- 首页预载「基准 A」和「竞速 B」，两趟都是确定性模拟数据。拖动时间轴、点击或拖动任一曲线，场地图和两条曲线共用同一光标。
- 「导入日志」支持 `tools/monitor_tuning.ps1` 保存的 VOFA 原始串口文本、同列顺序的 CSV，以及 `tools/capture_odom_warmup.ps1` 的 EmberProbe 调试 NDJSON。一次选多个文件会分别创建试跑，可在 A/B 切换。通过「档案与坐标」附加同趟文件时，副日志随档保存，主日志负责回放。
- 每个归档包含一趟试跑的元数据、解析样本、事件和导入的原始文本。保存生成 `*.longinus-run.json`，用同一个导入口恢复。固件、参数、路线和标定版本可在档案中填写。原文件不会被写回。
- 导入日志默认按自身记录起点对齐。两趟都有带时戳的进沟事件时，可用同一沟做对齐锚点。重启、时钟切换、采样缺口和缺失字段可在「日志字段与缺口」检查，曲线在标记处断开。没有时戳的文本事件只保留顺序。调试趋势文件通常没有 XY，只显示能取到的曲线。
- 未标定的 XY 在局部里程计坐标中绘制。场地叠图需要登记 `T_field_odom`，可从标定 JSON 读入，或者在已知起跑位姿时手工登记。多个里程计时钟段应拆开标定。

## 参数与标定

「参数草案」支持编辑限速、制动、观测时效和航向增益，预览当前假设下的制动距离，导出含基线版本、参数差异和参考试跑的 JSON。

「实测标定」含 FL、FR、RR、RL 逐轮步骤。先在架空工位核对电机 ID、正向和机械角，随后用带负载的独立距离和带符号编码器增量计算轮径。填写 IMU 轴向、场地和里程计的已知位姿，并用独立位姿复核变换。可记录四向激光测量。结果是待人工核验的 JSON 草案。

工作台不访问机器人、串口、调试器或网络服务。参数和标定文件需在另外的台架流程中验证后再应用。
